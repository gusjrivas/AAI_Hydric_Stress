# Notebooks de prueba parciales

Carpeta para notebooks exploratorios y de prueba (borradores, experimentos puntuales, verificaciones ad-hoc) que no forman parte de la documentación curada del proyecto.

No requieren limpiar outputs antes de subirlos ni seguir ninguna convención particular — a diferencia de `notebooks/exploracion_hu5_hu6.ipynb`, que sí es un notebook de referencia mantenido.

Si un notebook de esta carpeta madura en algo reutilizable (una exploración que vale la pena conservar como referencia), promoverlo a `notebooks/` y documentarlo ahí.
